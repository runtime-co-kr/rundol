# 보드 변경 인증과 동시성

## 배경

로컬 웹 페이지라도 다른 프로세스의 요청과 오래 열린 화면의 저장이 가능하므로, 변경 요청의 출처와 기준 상태를 검증하지 않으면 최신 데이터를 덮어쓸 수 있다.

## 요구사항

- 모든 GET 이외 요청은 서버 세션의 `X-Rundol-Token`과 일치하는 토큰을 포함해야 한다.
- 기존 태스크·문서·문서 계약 변경은 클라이언트가 읽은 `baseRevision`이 현재 revision과 일치할 때만 적용해야 한다.
- JSON 요청 본문은 64KiB 이하이고 올바른 JSON이어야 한다.

## 사전조건

- Board 서버가 암호학적으로 생성한 24바이트 hex 토큰 또는 명시적으로 주입한 테스트 토큰으로 실행 중이어야 한다.
- 변경 대상 프로젝트와 엔터티가 존재해야 한다.

## 동작 규칙

1. GET 이외 요청의 token이 없거나 다르면 본문을 적용하기 전에 403을 반환한다.
2. 태스크·문서·계약의 baseRevision이 없거나 현재 값과 다르면 변경하지 않고 409와 현재 엔터티를 반환한다.
3. 요청 본문 누적 크기가 64KiB를 넘으면 요청을 중단하고 오류를 반환한다.
4. 태스크 생성·변경은 필수 필드와 등록된 담당자·검토자·이해관계자를 검증한다.
5. Client, lease, 문서, 계약, 태스크, 협업, refresh, sync 변경은 각각의 도메인 저장 함수를 통해서만 수행한다.

## 상태와 예외

| 현재 상태 또는 상황 | 사건 | 기대 상태 또는 동작 |
|---|---|---|
| 토큰 일치 | 유효 POST | 도메인 검증 후 변경 적용 |
| 토큰 누락/불일치 | POST | 403, 상태 불변 |
| baseRevision 일치 | 기존 엔터티 변경 | 200과 변경 결과 |
| baseRevision 누락/불일치 | 기존 엔터티 변경 | 409과 `current`, 상태 불변 |
| 잘못된 JSON/64KiB 초과 | 요청 수신 | 오류 응답, 변경 없음 |
| 필수 필드 또는 등록 책임자 누락 | 태스크 변경 | 400, 변경 없음 |

## 수용 기준

- [ ] 잘못된 토큰의 변경 요청은 403이고 저장 상태가 바뀌지 않는다.
- [ ] 최신 revision의 태스크·문서·계약 변경은 성공하며 같은 revision을 재사용하면 409와 현재 데이터를 받는다.
- [ ] 유효하지 않은 태스크 입력과 등록되지 않은 담당자는 400으로 거절된다.

## 비기능 요구

| 품질 속성 | 기준 | 측정 방법 |
|---|---|---|
| 인증 | 모든 비-GET 요청에 동일한 서버 세션 토큰 적용 | endpoint 통합 테스트 |
| 동시성 | stale write는 영속 변경 전 409로 차단 | 연속 저장 통합 테스트 |
| 자원 제한 | 요청 본문 최대 64KiB | oversized request 테스트와 코드 검사 |

## 제외 범위

- GET 스냅샷의 필드 구성, UI 렌더링과 외부 사용자 인증 체계는 포함하지 않는다.

## 기능별 설계 계약

### BOP-02

#### 입력

- HTTP method/path, `X-Rundol-Token`, 최대 64KiB JSON body, 변경 대상에 필요한 `baseRevision`과 도메인 필드.

#### 출력

- 성공 시 200/201 JSON, 입력 오류 400, 인증 실패 403, stale revision 409와 `current`, 없는 경로 404, 기타 오류 500 JSON.

#### 업무 규칙

- 인증은 모든 비-GET endpoint에 선행하고 낙관적 동시성 검사는 기존 태스크·문서·계약 변경에 선행한다.

#### 상태와 전이

- current revision에서 검증된 변경만 새 revision으로 전이한다. stale·무인증·잘못된 입력은 현재 revision을 유지한다.

#### 권한과 승인

- 서버 토큰이 로컬 변경 권한이며 태스크 책임자 ID는 프로젝트 협업 디렉터리 등록 여부로 추가 승인한다.

#### 정상·오류·취소

- 정상 요청은 단일 도메인 변경을 완료한다. 오류는 JSON `{ error, current? }`로 반환되고 취소/연결 중단 시 불완전 body를 적용하지 않는다.

#### 감사 기록

- 영속 감사 정보는 호출된 도메인 저장소의 revision·operation·commit에 남고 HTTP 응답은 적용 결과와 현재 revision을 증거로 제공한다.

#### 수용 기준

- `test/board.test.js`와 `test/board-workspace.test.js`에서 토큰 403, 입력 400, 태스크·문서·계약 stale 409 및 current 반환이 통과한다.
