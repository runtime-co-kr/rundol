# 작업 할당 발급

## 배경

사람과 에이전트를 같은 계층의 워커로 운영하려면 작업 지시가 한 형식이어야 한다. 지금은 사람에게는 구두와 메신저로, 에이전트에게는 프롬프트로 지시가 나간다. 두 경로가 갈라져 있으면 같은 작업에 대한 지시가 서로 다른 내용을 담게 되고, 완료를 검수할 기준도 두 벌이 된다.

지시가 파일로 존재하지 않고 명령 순서와 사람의 기억에 흩어져 있는 것이 절차적 재현성이 서지 않는 원인이다. 같은 작업을 다시 시켰을 때 같은 절차로 실행된다는 보장이 없다.

또한 지시가 어떤 요구 조항에서 나왔는지가 남지 않으면 그 작업은 근거 없는 작업이 된다. 요구 조항과 작업을 잇는 자리가 할당이다.

## 요구사항

- 통제자는 하나의 할당을 발급하고, 사람 워커와 에이전트 워커는 그 할당에서 같은 내용을 읽는다.
- 할당은 어떤 기능 ID에서 나왔는지를 반드시 들고 있으며, 이를 통해 요구 조항과 작업의 덮임을 계산할 수 있다.
- 할당은 실행할 절차를 다이제스트로 고정해, 같은 할당을 다시 실행하면 같은 절차가 쓰인다.
- 수정 가능 범위가 이미 열린 다른 할당과 겹치면 발급을 거부해, 실행 중 잠금 없이도 동시 작업이 부딪히지 않는다.

## 사전조건

- 프로젝트가 연결되어 있고 프로젝트 브랜치의 worktree를 읽을 수 있다.
- 할당이 참조하는 기능 ID가 정규 문서에 선언되어 있다.
- 할당이 참조하는 절차가 해석 가능하며 그 revision을 다이제스트로 고정할 수 있다.
- 담당 워커의 종류가 사람 또는 에이전트 중 하나로 정해져 있다.

## 동작 규칙

1. 할당은 목표, 수용 조건, 기능 ID, 수정 가능 경로, 금지 항목, 절차 고정 참조, 보고 스키마 식별자, 담당 워커를 갖는다. 이 중 하나라도 없으면 발급하지 않는다.
2. 기능 ID가 비어 있으면 발급을 거부한다. 근거 없는 작업을 만들지 않는 것이 이 규칙의 목적이며, 탐색 작업은 별도 등급으로 다루되 할당으로 내보내지 않는다.
3. 수정 가능 경로가 아직 닫히지 않은 다른 할당의 수정 가능 경로와 교집합을 가지면 발급을 거부하고, 겹치는 할당의 식별자를 함께 반환한다.
4. 절차는 이름이 아니라 다이제스트로 고정한다. 절차 본문이 나중에 바뀌어도 이미 발급된 할당은 고정된 내용으로 실행된다.
5. 담당 워커가 사람이든 에이전트든 할당 본문은 같다. 워커 종류는 전달 경로만 결정하며 내용을 바꾸지 않는다.
6. 발급은 원격 없이 로컬에서 완료된다. 원격 동기화는 발급의 사전조건이 아니다.

## 상태와 예외

| 현재 상태 또는 상황 | 사건 | 기대 상태 또는 동작 |
|---|---|---|
| 필수 항목이 모두 있고 범위 겹침이 없다 | 발급 요청 | 할당을 발급하고 식별자와 절차 다이제스트를 반환하며 발급 사건을 원장에 남긴다. |
| 기능 ID가 비어 있다 | 발급 요청 | 발급을 거부하고 누락 항목을 이름으로 알린다. |
| 수정 가능 경로가 열린 할당과 겹친다 | 발급 요청 | 발급을 거부하고 겹치는 할당 식별자와 겹친 경로를 반환한다. |
| 참조한 절차를 해석할 수 없다 | 발급 요청 | 발급을 거부한다. 고정할 수 없는 절차로는 재현성이 성립하지 않는다. |
| 참조한 기능 ID가 정규 문서에 없다 | 발급 요청 | 발급을 거부하고 해당 기능 ID를 알린다. |
| 발급된 할당이 있다 | 보고 검수 통과 | 할당을 닫고 그 수정 가능 경로를 다른 할당이 쓸 수 있게 한다. |
| 발급된 할당이 있다 | 통제자의 취소 | 할당을 닫고 취소 사유를 원장에 남긴다. |

## 수용 기준

- [ ] 같은 할당을 사람 워커와 에이전트 워커에게 발급했을 때 두 워커가 읽는 할당 본문이 동일하다.
- [ ] 기능 ID가 없는 할당의 발급 시도가 거부되고 누락 항목이 이름으로 보고된다.
- [ ] 수정 가능 경로가 겹치는 두 할당을 동시에 열 수 없으며, 거부 응답이 겹치는 할당 식별자를 담는다.
- [ ] 발급된 할당이 절차 다이제스트를 포함하고, 절차 본문을 바꾼 뒤에도 그 값이 변하지 않는다.
- [ ] 원격 접속이 차단된 환경에서 발급이 성공한다.

## 비기능 요구

| 품질 속성 | 기준 | 측정 방법 |
|---|---|---|
| 결정성 | 같은 입력에서 같은 할당 본문과 같은 다이제스트가 나온다 | 동일 입력 반복 발급 후 본문 바이트 비교 |
| 로컬 우선 | 발급에 원격 왕복이 없다 | 네트워크 차단 환경에서 발급 시나리오 실행 |
| 판정 일관성 | 겹침 판정이 호출 표면과 무관하게 같다 | 명령줄과 보드에서 같은 입력으로 발급 시도 후 응답 비교 |

## 제외 범위

- 보고 제출과 검수 판정. 별도 기능으로 다룬다.
- 워커 실행 어댑터의 프로세스 수명 관리와 종료 보장.
- 할당의 화면 표시와 정렬 방식.
- 탐색·스파이크 같은 근거 없는 작업의 운영 방식.

## 기능별 설계 계약

### FN-001

#### 입력

- 목표: 워커가 달성해야 할 결과를 서술한 문장.
- 수용 조건: 관찰 가능한 조건의 목록. 최소 한 개.
- 기능 ID 목록: 이 할당이 덮는 정규 문서의 기능 식별자. 최소 한 개.
- 수정 가능 경로 목록: 워커가 변경해도 되는 경로 패턴.
- 금지 항목 목록: 이 할당에서 하지 않아야 할 일. 비어 있을 수 있다.
- 절차 참조: 절차 이름과 고정 대상 revision.
- 보고 스키마 식별자: 완료 보고가 따라야 할 스키마의 이름.
- 담당 워커: 종류(사람 또는 에이전트)와 식별자.

#### 출력

- 할당 식별자.
- 고정된 절차 다이제스트.
- 발급 시각과 발급자.
- 거부된 경우: 거부 사유 코드, 누락 항목 이름 목록, 겹치는 할당 식별자와 겹친 경로 목록.

#### 업무 규칙

- 필수 입력 중 하나라도 비어 있으면 발급하지 않고, 무엇이 비었는지를 이름으로 알린다.
- 기능 ID는 정규 문서에 선언된 것이어야 한다. 선언되지 않은 식별자는 거부한다.
- 수정 가능 경로의 교집합 판정은 아직 닫히지 않은 할당만을 대상으로 한다.
- 절차는 이름이 아니라 다이제스트로 고정하며, 고정에 실패하면 발급하지 않는다.
- 워커 종류는 전달 경로만 결정하고 할당 본문에 영향을 주지 않는다.
- 겹침 판정과 필수 항목 판정은 파일 접근 없이 값만으로 수행할 수 있어야 한다.

#### 상태와 전이

- 없음에서 열림: 발급이 성공하면 할당은 열림 상태가 된다.
- 열림에서 닫힘: 보고가 검수를 통과하거나 통제자가 취소하면 닫힘 상태가 된다.
- 닫힘에서 전이 없음: 닫힌 할당은 다시 열리지 않으며, 다시 시키려면 새 할당을 발급한다.
- 열림 상태의 할당만 겹침 판정의 대상이다.

#### 권한과 승인

- 발급은 통제 권한을 가진 주체만 수행한다. 워커는 자기 자신에게 할당을 발급하지 않는다.
- 취소는 발급자 또는 그 권한을 위임받은 주체가 수행한다.
- 워커는 자신에게 배정된 할당을 읽을 수 있고, 내용을 바꿀 수 없다.
- 권한 판정은 발급 시점의 사실로 기록하며, 이후 주체의 상태 변화가 과거 발급의 유효성을 바꾸지 않는다.

#### 정상·오류·취소

- 정상: 필수 항목이 모두 있고 겹침이 없으면 할당 식별자와 절차 다이제스트를 반환한다.
- 오류(입력): 누락 항목, 미선언 기능 ID, 해석 불가 절차는 각각 구분되는 사유 코드로 거부한다. 부분 발급은 없다.
- 오류(충돌): 범위 겹침은 거부이며 실패가 아니다. 겹치는 할당을 알려 통제자가 다시 판단하게 한다.
- 취소: 열린 할당은 사유와 함께 닫을 수 있다. 취소는 워커의 작업 결과를 지우지 않으며, 보고가 이미 있으면 그 보고는 남는다.
- 어떤 경로에서도 기존 할당을 조용히 덮어쓰지 않는다.

#### 감사 기록

- 발급 사건에 할당 식별자, 기능 ID 목록, 절차 다이제스트, 담당 워커, 발급자, 발급 시각을 남긴다.
- 거부 사건에도 사유 코드와 입력 요약을 남긴다. 거부는 침묵하지 않는다.
- 닫힘 사건에 닫힌 이유(검수 통과 또는 취소)와 시각을 남긴다.
- 기록은 추가만 하며 기존 사건을 수정하지 않는다.

#### 수용 기준

- 필수 항목 여덟 가지가 모두 있는 입력이 할당 식별자와 절차 다이제스트를 반환한다.
- 기능 ID가 빈 입력이 거부되고 응답이 누락 항목으로 기능 ID를 지목한다.
- 열린 할당과 수정 가능 경로가 겹치는 입력이 거부되고 응답이 겹치는 할당 식별자를 담는다.
- 절차 본문을 바꾼 뒤 같은 할당을 다시 읽어도 절차 다이제스트가 변하지 않는다.
- 사람 워커와 에이전트 워커에게 발급한 두 할당의 본문이 담당 워커 항목을 제외하고 동일하다.
- 발급·거부·닫힘이 각각 원장 사건으로 남는다.
