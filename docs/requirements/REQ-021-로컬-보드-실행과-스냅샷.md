# 로컬 보드 실행과 스냅샷

## 배경

사용자는 여러 파일과 Git 상태를 직접 조합하지 않고도 로컬 브라우저에서 프로젝트 진행 상태와 주의 항목을 일관되게 확인해야 한다.

## 요구사항

- Board 서버는 `127.0.0.1`에 바인딩하고 정적 UI와 읽기 전용 조회 API를 제공해야 한다.
- 프로젝트 스냅샷은 태스크, 문서, 협업 디렉터리, Client, lease, 동기화, 문서 계약, 표시 설정, 주의 항목과 각 revision을 함께 반환해야 한다.

## 사전조건

- 시작 경로에서 Rundol Workspace와 대상 프로젝트를 발견할 수 있어야 한다.
- 대상 프로젝트의 태스크 저장소가 존재해야 한다.

## 동작 규칙

1. 명시한 프로젝트가 없으면 Workspace의 첫 프로젝트를 사용하고, 포트를 생략하면 사용 가능한 포트를 선택한다.
2. 태스크 목록은 검색·owner·priority·status 필터와 offset/limit을 지원하며 limit은 1~500으로 제한한다.
3. 스냅샷은 각 데이터 집합의 content revision과 Workspace board revision을 제공한다.
4. 미할당·완료조건 없음·reviewer 없음·미완료 의존성·깨진 문서 링크·불완전 sync는 attention 항목으로 계산한다.
5. UI 자산은 no-store 또는 제한된 캐시, CSP, nosniff, frame deny 보안 헤더로 제공한다.

## 상태와 예외

| 현재 상태 또는 상황 | 사건 | 기대 상태 또는 동작 |
|---|---|---|
| 유효 Workspace와 프로젝트 | 서버 시작 | loopback URL·port·token 반환 |
| 유효 조회 경로 | GET | 200과 JSON 또는 정적 자산 반환 |
| 없는 프로젝트·태스크·문서 | GET | 404 또는 프로젝트 선택 오류 |
| 태스크 파일 없음 | 시작/조회 | 파일 경로를 포함한 오류 |
| sync dirty/conflict | snapshot | warning/error attention 항목 포함 |

## 수용 기준

- [ ] 루트 UI와 Mermaid·Marked·DOMPurify·theme 자산이 200으로 제공되고 CSP가 설정된다.
- [ ] `/api/projects/<key>/board-snapshot`이 프로젝트 ID, 문서 본문, 태스크, attention, contract, presentation과 문자열 revision들을 반환한다.
- [ ] 태스크 필터는 status와 limit을 적용하고 상태별 count와 5개 상태 목록을 제공한다.

## 비기능 요구

| 품질 속성 | 기준 | 측정 방법 |
|---|---|---|
| 네트워크 격리 | 서버는 `127.0.0.1`에만 listen | 서버 통합 테스트 |
| 보안 표시 | CSP `default-src 'self'`, frame deny, nosniff 적용 | 응답 헤더 검사 |
| 결정성 | revision은 동일 데이터에 동일 문자열을 반환 | snapshot/board 테스트 |

## 제외 범위

- POST 요청의 세션 인증, 본문 크기 제한, baseRevision 충돌 처리는 REQ-022에서 다룬다.

## 기능별 설계 계약

### FN-001

#### 입력

- Workspace 시작 경로, 선택적 `project`, `port`, `token`, 브라우저 열기 옵션과 GET query.

#### 출력

- 서버 시작 시 `{ server, token, root, url, port }`; 조회 시 프로젝트 overview, filtered tasks 또는 통합 board snapshot JSON.

#### 업무 규칙

- snapshot은 프로젝트별 실제 저장소를 읽고 schemaVersion 6 이상에서 Client와 lease를 포함하며 표시 설정 상속 결과를 적용한다.

#### 상태와 전이

- 서버는 생성 → loopback listen → 요청 처리 → close 수명주기를 가지며 조회는 저장 상태를 변경하지 않는다.

#### 권한과 승인

- GET 조회는 로컬 서버에서 토큰 없이 허용하지만 서버가 외부 인터페이스에 바인딩되어서는 안 된다.

#### 정상·오류·취소

- 정상 조회는 200, 없는 개별 자원은 404, Workspace·프로젝트·파일 발견 실패는 JSON 오류로 반환한다. 서버 종료가 실행 취소다.

#### 감사 기록

- 읽기 동작은 영속 감사 사건을 만들지 않으며 반환된 workspace/tasks/documents 등 revision이 관찰 시점의 증거다.

#### 수용 기준

- `test/board.test.js`, `test/board-workspace.test.js`, `test/board-ui.test.js`의 loopback, 자산, 필터, snapshot, revision, 표시 검증이 통과한다.
