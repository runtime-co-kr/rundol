# 프로젝트 연결과 복구

## 배경

새 clone이나 손상된 로컬 worktree에서 Rundol 브랜치를 코드 작업 트리와 혼합하지 않고 `projects/workspace`, `projects/<key>`에 연결해야 한다.

## 요구사항

- `attached`는 원격 commit을 로컬 ref로 연결하고 Workspace와 선택 project worktree를 추가한다.
- `repaired`는 유효한 로컬 ref를 사용해 누락된 worktree를 복구한다.
- 연결 후 branch boundary hook과 `/projects/*/` Git exclude를 설치한다.

## 사전조건

- WSP-01 발견 결과가 `attached`, `repaired`, `already-connected` 또는 프로젝트가 지정된 상태여야 한다.
- 대상 경로는 없거나 비어 있어야 하고 지정 브랜치와 충돌하는 worktree가 없어야 한다.

## 동작 규칙

1. 원격 commit object가 로컬에 존재하는지 확인한 뒤 ref를 생성하거나 fast-forward만 한다.
2. 대상 worktree가 이미 존재하면 branch role·project key·canonical 경계를 검증하고 재사용한다.
3. 후보가 복수인데 project를 지정하지 않으면 `needs-selection`으로 종료한다.
4. 모든 대상의 빈 경로와 branch 일치를 먼저 검사한 뒤 ref·worktree를 변경한다.

## 상태와 예외

| 상황 | 사건 | 기대 동작 |
|---|---|---|
| 이미 연결됨 | attach/repair | `already-connected`, 추가 worktree 없음 |
| 원격 Workspace 존재 | attach | `attached`, 전용 worktree 생성 |
| 로컬 ref 존재·worktree 누락 | repair | `repaired` |
| 프로젝트 미지정·후보 복수 | repair | `needs-selection` |
| 비어 있지 않은 대상 또는 분기 ref | attach/repair | 오류, 기존 파일과 ref 보존 |

## 수용 기준

- [x] 원격 복제본에 `rdl attach <key>`를 실행하면 Workspace와 project worktree가 올바른 브랜치로 연결된다.
- [x] `rdl init --project <key>`는 발견된 원격 프로젝트를 attach 경로로 연결한다.
- [x] 비어 있지 않은 대상 경로에서는 실패하고 Workspace worktree와 Rundol ref를 남기지 않는다.
- [x] 코드 worktree의 `git status` 결과는 attach 전후에 동일하다.

## 비기능 요구

| 품질 속성 | 기준 | 측정 방법 |
|---|---|---|
| 원자성 | 대상 사전 검사 실패 시 부분 연결 없음 | conflict clone 통합 테스트 |
| 멱등성 | 이미 연결된 상태의 재실행이 worktree를 중복 생성하지 않음 | action과 worktree 목록 비교 |
| 경계 안전성 | Workspace와 project가 각 전용 브랜치에 존재 | boundary 검사 |

## 제외 범위

- 신규 `project.md`, registry, 문서 profile 생성
- detach, save, sync, 의미 병합

## 기능별 설계 계약

### WSP-02

#### 입력

- Git root, remote, 선택 project key, WSP-01 discovery snapshot

#### 출력

- action, Workspace branch·commit·worktree, attached project 배열, exclude·boundary 설치 결과

#### 업무 규칙

- Workspace는 `projects/workspace`, project는 `projects/`아래 project key 디렉터리에만 연결하고 원격 commit에서 fast-forward 가능한 ref만 갱신한다.

#### 상태와 전이

- `attached`는 원격에서 로컬 연결로, `repaired`는 로컬 ref에서 worktree 연결로 전이한다.

#### 권한과 승인

- 로컬 ref·worktree·Git exclude를 쓸 권한이 필요하며 project 선택은 명시적 CLI 인수로 승인한다.

#### 정상·오류·취소

- 정상은 연결 결과를 반환하고, 선택 필요는 무변경으로 반환하며, 충돌·분기·remote 누락은 오류로 중단한다.

#### 감사 기록

- 연결된 branch·commit·target과 branch boundary 설치 결과를 CLI JSON으로 반환하고 Git worktree/ref로 추적한다.

#### 수용 기준

- `test/attach.test.js`와 `test/bootstrap.test.js`의 attach, init-bootstrap, occupied target, repair 시나리오가 통과한다.
