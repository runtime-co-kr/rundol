# 사람 결정 요청과 응답

## 배경

에이전트가 절차를 실행하다 사람이 정해야 하는 지점에 닿으면, 지금은 물을 자리가 없어 대화로 묻고 대화로 답한다. 그 답은 세션과 함께 사라져 다음 세션이 같은 것을 다시 묻거나 묻지 않고 결정한다. [[ADR-008-사람-결정의-기록-방식|ADR-008]]은 이 문제를 질문을 기록되는 결정으로 두어 해결하기로 정했고, 이 문서는 그 결정이 실제로 무엇을 판정하고 무엇을 남기는지 정한다.

## 요구사항

- 되돌릴 수 없거나, 이 머신을 벗어나거나, 다른 주체의 권한을 덮거나, 요청 범위를 벗어나는 작업은 사람의 결정 없이 수행하지 않는다.
- 검사가 판정할 수 있는 것과 안전한 기본값이 있는 것은 묻지 않는다.
- 결정 요청은 질문, 닫힌 선택지, 권고안과 근거, 영향의 가역성을 함께 담는다.
- 답변이 없는 동안 해당 작업은 진행하지 않는다.
- 답변은 결정자와 사유를 포함해 기록되며 어느 클라이언트에서나 읽고 답할 수 있다.
- 같은 결정을 이미 답했으면 다시 묻지 않는다.

## 사전조건

- Workspace와 대상 프로젝트가 연결돼 있어야 한다.
- 답변자는 project.md에 등록된 멤버여야 한다.
- 결정 요청을 만드는 주체는 등록된 활성 Client여야 한다.

## 동작 규칙

1. 결정이 필요한 지점은 작업의 종류가 아니라 그 작업의 성질로 판정한다. 판정 기준은 비가역성, 외부 노출, 권한 우회, 요청 범위 이탈 네 가지다.
2. 요청에는 권고안이 반드시 있다. 권고 없는 질문은 판단을 떠넘기는 것이므로 요청으로 인정하지 않는다.
3. 선택지는 닫힌 목록이다. 목록 밖의 판단이 필요하면 사유란에 적고 선택지 중 하나를 고른다.
4. 답변이 없으면 기본 동작은 정지다. 어떤 결정 종류도 무응답을 진행으로 해석하지 않는다.
5. 정지는 작업 전체가 아니라 그 지점에 걸린다. 여러 작업을 연속 실행하는 중이라면 해당 항목만 대기로 내려놓고 나머지는 계속한다.
6. 결정 요청과 답변은 같은 기록에 남는다. 절차의 사람 스텝과 태스크의 대기 상태는 이 기록을 공유하며 각자 별도의 질문 저장소를 두지 않는다.
7. 같은 결정 종류·범위·대상의 요청은 하나로 본다. 이미 답한 결정은 다시 묻지 않고 기존 답변을 적용한다.
8. 답변자의 권한은 결정 종류가 정한다. 권한이 없는 주체의 답변은 기록되지 않고 거부된다.

## 상태와 예외

| 현재 상태 또는 상황 | 사건 | 기대 상태 또는 동작 |
|---|---|---|
| 결정이 필요한 지점 도달 | 실행 | 요청을 기록하고 그 지점에서 정지한다. |
| 요청 대기 중 | 권한 있는 답변 | 답변을 기록하고 작업을 재개한다. |
| 요청 대기 중 | 권한 없는 답변 | 거부하고 요청은 대기 상태로 남는다. |
| 이미 답변된 결정 | 같은 결정 재도달 | 다시 묻지 않고 기존 답변을 적용한다. |
| 연속 실행 중 요청 발생 | 실행 | 해당 항목만 대기로 내려놓고 나머지 항목은 계속한다. |

## 수용 기준

- [ ] 비가역·외부·권한 우회·범위 이탈 작업이 결정 없이 수행되지 않는다.
- [ ] 검사로 판정 가능한 사안과 안전한 기본값이 있는 사안은 요청을 만들지 않는다.
- [ ] 요청과 답변이 결정자·사유와 함께 남아 다른 클라이언트에서 읽힌다.
- [ ] 이미 답한 결정이 재질문되지 않는다.

## 비기능 요구

| 품질 속성 | 기준 | 측정 방법 |
|---|---|---|
| 결정성 | 같은 상태에서 같은 결정 종류가 판정된다. | 단위 테스트 deep equality |
| 안전성 | 무응답의 기본 동작은 항상 정지다. | 결정 종류별 회귀 테스트 |
| 비동기성 | 요청한 클라이언트가 아닌 곳에서도 답변할 수 있다. | 다중 클라이언트 통합 테스트 |
| 감사성 | 결정자와 사유 없이 기록된 답변이 없다. | 검사 진단 |

## 제외 범위

- 결정 위임의 부여·범위·만료·취소
- 초기 설정에서 수집하는 입력 목록과 인터뷰 흐름
- 답변을 위한 화면 구현

## 기능별 설계 계약

### DEC-01

#### 입력

- 수행하려는 작업의 종류와 대상, 그 작업의 가역성과 영향 범위, 현재 프로젝트와 실행 주체

#### 출력

- 질문·닫힌 선택지·권고안과 근거·가역성을 담은 결정 요청 기록, 또는 이미 답변된 결정의 적용 결과

#### 업무 규칙

- 비가역성, 외부 노출, 권한 우회, 요청 범위 이탈 중 하나에 해당할 때만 요청을 만든다. 검사가 판정할 수 있거나 안전한 기본값이 있으면 요청하지 않고 선택한 기본값을 결과에 밝힌다. 요청에는 권고안이 반드시 포함된다.

#### 상태와 전이

- 요청은 대기에서 시작해 권한 있는 답변으로 해소되며, 해소 전까지 해당 작업은 진행하지 않는다. 같은 결정 종류·범위·대상의 요청은 하나로 취급해 기존 답변이 있으면 대기 없이 적용된다.

#### 권한과 승인

- 요청은 등록된 활성 Client가 만들고, 답변은 결정 종류가 정한 권한을 가진 project.md 등록 멤버만 할 수 있다. 권한 없는 답변은 기록되지 않는다.

#### 정상·오류·취소

- 권한 있는 답변은 작업을 재개시키고, 권한 없는 답변과 선택지 밖의 값은 거부되며 요청은 대기로 남는다. 답변이 없는 채로 실행이 끝나면 작업은 진행되지 않은 상태로 남고 재개할 수 있다.

#### 감사 기록

- 요청과 답변은 질문·선택지·권고안·선택된 값·결정자·사유와 함께 기록되어, 실행 원장과 함께 다시 읽을 때 왜 그렇게 되었는지가 복원된다.

#### 수용 기준

- 비가역 작업이 답변 없이 수행되지 않고, 다른 클라이언트에서 답한 결정으로 작업이 재개되며, 이미 답한 결정은 다시 묻지 않는다.
