# 그림 자산의 규격 한계

## 배경

이 저장소는 문서 93개 전체가 780KB다. 화면 갈무리 한 장이 300KB면 그 하나가 문서 전체의 40%다. 방치하면 문서 브랜치는 곧 그림 브랜치가 되고, 문서만 받고 싶은 쪽도 그림을 함께 받게 된다.

Git LFS는 답이 아니다. 체크아웃에 네트워크가 필요해 로컬 우선 원칙과 폐쇄망 운영을 동시에 깨고, 한 번 들어간 것을 빼려면 히스토리를 다시 써야 한다. 그래서 답은 저장 방식을 바꾸는 것이 아니라 무엇이 들어오는지를 재는 것이다.

## 요구사항

- 자산의 용량과 차원을 재고 한계를 넘으면 알려야 한다.
- 형식을 알아보지 못한 파일이 자산 디렉터리에 있으면 알려야 한다.
- 어느 문서도 참조하지 않는 자산을 알려야 한다.

## 사전조건

- 자산 디렉터리를 읽을 수 있다.
- 어느 자산이 참조되는지는 REQ-052#FN-001이 모아 준다.

## 동작 규칙

1. 차원은 헤더 앞부분만 읽어 잰다. 디코딩하지 않는다 — 디코딩이 필요한 것은 변환이지 판정이 아니다.
2. 용량이 한계를 넘으면 `RDL-ASSET-002`.
3. 긴 변이 한계를 넘으면 `RDL-ASSET-003`.
4. 형식을 알아보지 못하면 `RDL-ASSET-004`.
5. 참조 집합에 없으면 `RDL-ASSET-005`.
6. 한 자산이 여러 진단에 걸릴 수 있다. 첫 진단에서 멈추지 않는다 — 용량만 알려주고 차원을 감추면 압축만 해 보고 다시 걸린다.
7. 넷 다 경고다. 오류로 막으면 이미 쌓인 저장소가 판올림만으로 멈춘다.

## 상태와 예외

| 현재 상태 또는 상황 | 사건 | 기대 상태 또는 동작 |
|---|---|---|
| 자산이 한계 안이고 참조됨 | 검사 실행 | 진단 없음 |
| 자산이 용량 한계 초과 | 검사 실행 | `RDL-ASSET-002`와 줄이는 방법 |
| 자산이 차원 한계 초과 | 검사 실행 | `RDL-ASSET-003` |
| 형식을 알아보지 못함 | 검사 실행 | `RDL-ASSET-004` |
| 아무 문서도 가리키지 않음 | 검사 실행 | `RDL-ASSET-005` |
| 자산 디렉터리가 없음 | 검사 실행 | 진단 없음. 없는 것은 위반이 아니다 |

## 수용 기준

- [ ] 한계를 넘는 자산이 파일과 함께 지목된다.
- [ ] 참조되면 고아 진단이 사라진다.
- [ ] 자산 디렉터리가 없어도 검사가 그대로 통과한다.

## 비기능 요구

| 품질 속성 | 기준 | 측정 방법 |
|---|---|---|
| 읽기 비용 | 자산 하나당 헤더 4KB만 읽는다 | 자산 수 × 4KB 이하 |
| 판정 순수성 | 잰 값만 보고 판정한다 | 전이 의존 검사 |

## 제외 범위

- 그림을 줄이는 일은 REQ-054#FN-001이 한다. 여기서는 재고 알릴 뿐이다.
- 자산 참조의 해결은 REQ-052#FN-001이 한다.
- 자산 총량 한계는 지금 두지 않는다. 개별 한계로 충분한지 재 본 뒤에 정한다.

## 기능별 설계 계약

### FN-001

#### 입력

- 자산 이름에서 `{ 상대경로, 바이트, 형식, 너비, 높이 }`로 가는 사전.
- 참조된 자산 이름 집합.
- 용량과 긴 변 한계.

#### 출력

- 진단 목록. 한 자산이 여러 진단에 걸릴 수 있다.

#### 업무 규칙

- 기본 한계는 용량 512KB, 긴 변 2560px다. 뒤엣것은 레티나 갈무리가 그 두 배로 찍히기 때문이다.
- 형식을 알아보지 못한 자산은 차원을 없음으로 둔다. 0으로 두면 "매우 작은 이미지"로 읽혀 판정을 통과한다.

#### 상태와 전이

- 판정은 상태를 갖지 않는다.
- 문서를 다 훑은 뒤에 한 번 부른다. 문서마다 부르면 아직 안 본 문서가 참조하는 자산을 고아라고 말하게 된다.

#### 권한과 승인

- 없다.

#### 정상·오류·취소

- 정상: 진단 없음.
- 오류: 넷 중 해당하는 코드 전부. 경고 심각도다.
- 취소: 없음.

#### 감사 기록

- 진단이 기록이다.

#### 수용 기준

- [ ] 용량과 차원 진단이 각각 독립으로 난다.
- [ ] 고아 판정이 전체 문서를 훑은 뒤의 참조 집합을 쓴다.
