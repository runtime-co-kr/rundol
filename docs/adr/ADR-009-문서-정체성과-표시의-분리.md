# 문서 정체성과 표시의 분리

## 맥락

지금 문서를 가리키는 키는 순차 번호다. `REQ-010`이 파일 이름이고, 태스크의 연결이고, 추적성의 조인 키이고, 사람이 읽는 이름이다. 하나가 네 가지 역할을 겸하면 그중 하나를 바꿀 때 나머지가 전부 흔들린다.

두 가지 증상이 실제로 나타났다. 첫째, 번호에 구멍이 생긴다. 병렬 에이전트가 번호를 예약한 뒤 작업이 중단되거나, 만든 문서를 지우면 그 번호는 소비된 채 남는다. 다중 클라이언트와 중단 가능한 실행을 전제하는 한 이 구멍은 원리적으로 없앨 수 없다. 둘째, 정리가 어렵다. 번호를 다시 매기거나 문서 이름을 바꾸면 그것을 가리키던 모든 연결이 깨진다.

더 중요한 것은 채번의 비용이다. 번호를 안전하게 나눠 주려면 클라이언트들이 합의해야 하고, 그래서 문서를 하나 만들 때마다 원격 저장소에 예약 이벤트를 밀어 넣고 충돌하면 다시 시도한다. Rundol의 다른 모든 식별자는 각자 만들어 쓰는데, 문서 번호만 남은 유일한 원격 조율 지점이다. 오프라인에서는 문서를 만들 수 없고, 병렬 에이전트는 서로를 밀어낸다.

## 결정 기준

- 조율 제거: 식별자 발급이 다른 클라이언트나 네트워크를 필요로 하지 않아야 한다.
- 안정성: 이름과 번호를 바꿔도 도구의 연결이 살아남아야 한다.
- 사람의 가독성: 저장소를 열었을 때 파일 이름으로 무엇인지 알 수 있어야 한다.
- 옵시디언 보존: 기존 위키 링크, 그래프, 백링크가 그대로 동작해야 한다.

## 선택지

| 선택지 | 장점 | 단점 | 위험 |
|---|---|---|---|
| 순차 번호 유지 | 사람이 읽고 정렬하기 쉽다 | 발급에 원격 조율이 필요하고 재채번이 연결을 깬다 | 오프라인 생성 불가, 병렬 생성 충돌, 구멍 누적 |
| 내용 해시를 키로 | 발급에 조율이 없다 | 내용이 바뀌면 키가 바뀐다 | 문서를 고칠 때마다 정체성이 사라진다 |
| 조율 없는 짧은 난수 키 + 번호·제목은 표시 | 조율이 없고 재채번이 안전하다 | 식별자 공간이 두 개가 되고 마이그레이션이 필요하다 | 표시와 키가 어긋나면 사람이 읽는 것과 도구가 보는 것이 갈린다 |

## 결정

**조율 없는 짧은 고유 식별자를 조인 키로 두고, 번호와 제목은 표시로 내린다.**

식별자는 내용 해시가 아니라 난수 기반이다. 내용 해시는 문서를 고칠 때마다 정체성이 바뀌므로 키가 될 수 없다. 길이는 프로젝트 범위 안에서 충돌이 실질적으로 없을 만큼만 짧게 잡고, 그래도 남는 충돌 가능성은 조용한 손상이 아니라 검사 진단으로 드러낸다. 짧게 잡는 이유는 이 값이 로그가 아니라 사람이 명령줄과 변경 이력에서 보는 값이기 때문이다.

**파일 이름은 사람이 읽는 그대로 둔다.** 옵시디언은 파일 이름으로 링크를 푼다. 키를 파일 이름에 넣으면 저장소가 읽을 수 없는 문자열의 목록이 되고, 그것은 이 결정이 지키려는 가독성을 스스로 깨는 일이다. 사람과 옵시디언은 계속 제목과 번호로 링크하고, 도구의 연결만 키로 옮긴다.

**표시 계층의 정리는 도구가 일괄로 한다.** 키가 있다고 링크가 저절로 고쳐지지는 않는다. 번호를 다시 매기거나 이름을 바꿀 때 파일 이름·번호·본문 링크를 한 번에 갱신하는 명령이 있어야 이 결정의 이득이 실현된다.

## 결과

- 긍정적 결과: 문서 생성에서 원격 조율이 사라져 오프라인에서도 만들 수 있고 병렬 생성이 서로를 밀어내지 않는다. 번호의 구멍은 표시상의 빈칸이 되어 언제든 다시 채울 수 있다. 이름과 번호를 바꿔도 태스크 연결과 추적성이 살아남는다.
- 부정적 결과: 식별자 공간이 둘이 되어 배우고 설명할 것이 늘어난다. 기존 문서 전부에 키를 소급 부여하는 마이그레이션이 필요하다. 변경 이력에서 연결이 사람 눈에 덜 읽히므로 표시 이름을 함께 남기는 배려가 필요하다.
- 후속 작업: 부여·마이그레이션·조인 이전과 재정렬 명령은 별도 요구사항으로 다룬다. 문서 번호와 요청 식별자가 같은 접두를 쓰는 기존 혼동도 이때 함께 정리한다.
- 재검토 조건: 키가 사람의 작업 흐름에 자주 노출되어 번호보다 자주 읽히게 된다면, 표시 계층이 제 역할을 못 하는 것이므로 표시 규칙을 다시 본다.
