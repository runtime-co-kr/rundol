# 워크스페이스 초기화와 발견 검증

## 목적과 범위

`discoverWorkspace` 결과가 로컬·원격 ref, registry, worktree 상태에 따라 정확한 action을 내고 발견 중 ref·파일을 변경하지 않음을 검증한다. worktree 생성 자체는 TST-005의 범위다.

## 테스트 수준

| 수준 | 대상 | 책임 | 자동화 여부 |
|---|---|---|---|
| 단위 | `src/bootstrap.js` action 결정 | 개발자 | 자동 |
| Git 통합 | 로컬·bare remote·worktree fixture | 개발자 | 자동 |

## 시나리오

| ID | 사전조건 | 실행 | 기대 결과 | 우선순위 |
|---|---|---|---|---|
| WSP01-01 | Rundol 흔적 없는 Git repo | remote 제외 발견 | `created`, available `[]`, show-ref 무변경 | P0 |
| WSP01-02 | manifest는 있고 Workspace ref 없음 | 발견 | `conflict` | P0 |
| WSP01-03 | 원격 Workspace에 alpha/beta 등록 | project 미지정 발견 | `needs-selection`, 정렬된 available, ref·projects 무변경 | P0 |
| WSP01-04 | 유효하지 않은 Workspace ref | 발견 | `conflict`, `branchValid: false` | P0 |
| WSP01-05 | project worktree가 다른 branch | 발견 | `conflict`, mismatchedTrees에 project 포함 | P0 |
| WSP01-06 | project ref는 유효, worktree 누락 | 발견 | `repaired` | P1 |
| WSP01-07 | 로컬·원격 Workspace 분기 | 발견 | `conflict`, relation `diverged` | P0 |

## 비기능 검증

| 품질 속성 | 목표 | 환경 | 측정 방법 |
|---|---|---|---|
| 무변경 | 발견 전후 ref·projects 파일 동일 | 임시 Git/bare repo | `show-ref`, 파일 존재 비교 |
| 결정성 | 상태별 action 일치 | Windows/Linux Git CI | strict equality |

## 테스트 데이터와 환경

Node `fs.mkdtempSync` 임시 repo, 로컬 bare remote, 테스트용 Git 사용자를 사용한다. 외부 네트워크와 개인정보는 없고 `finally`에서 임시 경로를 제거한다.

## 통과 기준

- `node test/bootstrap.test.js`가 exit 0으로 완료되고 모든 action·무변경 단언이 통과한다.

## 기능별 검증 계약

### WSP-01

#### 사전 조건

- Git CLI와 Node.js가 사용 가능하고 매 시나리오가 독립 임시 repo를 갖는다.

#### 입력과 데이터

- manifest/ref/worktree 조합, 원격 project alpha·beta, 선택 project, remote 여부

#### 실행 절차

- fixture를 구성하고 `discoverWorkspace(root, options)`를 호출한 뒤 action·available·relation·local 진단과 Git 전후 상태를 비교한다.

#### 기대 결과

- 상태별 계약 action이 일치하고 created/needs-selection에서 ref와 파일이 변하지 않는다.

#### 오류와 취소

- invalid ref, wrong worktree, diverged history는 예외 대신 `conflict` snapshot을 반환하고 후속 변경을 실행하지 않는다.

#### 증거

- `test/bootstrap.test.js` assert, `bootstrap tests passed` 표준 출력, 테스트 프로세스 exit code

#### 수용 기준

- WSP01-01~07이 모두 통과하고 임시 자원 정리 후 잔존 ref·worktree가 없다.
