# 에이전트 협업 하네스 검증

## 목적과 범위

사람이 결정해야 하는 지점에서 작업이 멈추고, 그 질문과 답변이 다른 클라이언트에서도 읽히고 답해지는지를 검증한다. 문서 계약 평가기 자체의 규칙과 보드 화면 흐름은 각각의 검증 문서가 다루므로 여기서 제외한다.

이 문서는 에이전트 협업 하네스의 여러 기능이 같은 회귀 스위트와 같은 픽스처 흐름을 공유하기 때문에 하나로 유지한다. 기능이 늘어나면 이 문서에 검증 계약을 추가한다.

## 테스트 수준

- 단위: 결정 종류 판정과 무응답 기본 동작
- 통합: 요청 기록에서 정지, 다른 클라이언트의 답변으로 재개
- 회귀: 이미 답변된 결정의 재질문 없음

## 시나리오

- 비가역 작업이 답변 없이 수행되지 않고 요청이 기록된 채 정지한다.
- 검사로 판정 가능한 사안과 안전한 기본값이 있는 사안에서는 요청이 만들어지지 않는다.
- 요청을 만든 클라이언트가 아닌 다른 클라이언트가 답변하고, 원래 작업이 그 답변으로 재개된다.
- 권한 없는 주체의 답변이 거부되고 요청은 대기로 남는다.
- 여러 작업을 연속 실행하는 중 한 항목에서 요청이 생겨도 나머지 항목이 계속된다.

## 비기능 검증

- 같은 상태에서 같은 결정 종류가 판정되는지 deep equality로 확인한다.
- 결정자와 사유 없이 기록된 답변이 없는지 검사 진단으로 확인한다.

## 테스트 데이터와 환경

- 임시 Workspace에 프로젝트 하나와 등록된 Client 둘, 등록 멤버 하나를 둔다.
- 답변자 권한 검증을 위해 멤버가 아닌 주체를 하나 포함한다.
- 벽시계에 의존하는 단언을 두지 않는다.

## 통과 기준

- 위 시나리오가 모두 통과하고, 무응답 상태에서 작업이 진행된 흔적이 원장에 없다.

## 기능별 검증 계약

### DEC-01

#### 사전 조건

- 프로젝트와 등록 멤버 하나, 활성 Client 둘이 있는 임시 Workspace가 준비되어 있다.

#### 입력과 데이터

- 비가역 작업 하나, 검사로 판정 가능한 작업 하나, 안전한 기본값이 있는 작업 하나와 각각의 대상 식별자

#### 실행 절차

- 세 작업을 차례로 실행하고, 생성된 요청을 다른 Client에서 조회해 권한 없는 주체와 권한 있는 멤버가 차례로 답한 뒤 원래 작업을 다시 실행한다.

#### 기대 결과

- 비가역 작업만 요청을 만들고 정지하며, 권한 있는 답변 뒤 재개되어 완료된다. 나머지 두 작업은 요청 없이 수행되고 선택한 기본값이 결과에 표시된다.

#### 오류와 취소

- 권한 없는 답변과 선택지 밖의 값은 거부되고 요청은 대기로 남으며, 답변 없이 실행이 끝나면 작업은 진행되지 않은 상태로 남는다.

#### 증거

- 요청과 답변 기록, 재개 후 실행 결과, 그리고 무응답 구간에 진행 이벤트가 없다는 원장 단언

#### 수용 기준

- 무응답에서 진행이 없고, 다른 클라이언트의 권한 있는 답변으로 재개되며, 같은 결정이 다시 질문되지 않는다.
