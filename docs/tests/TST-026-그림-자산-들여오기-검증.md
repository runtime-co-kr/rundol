# 그림 자산 들여오기 검증

## 목적과 범위

들여오기와 자동 축소를 검증한다. 사람의 눈으로 보는 화질은 이 시험의 대상이 아니며, 대비가 큰 무늬로 왕복 무손실만 확인한다.

## 테스트 수준

| 수준 | 대상 | 책임 | 자동화 여부 |
|---|---|---|---|
| 단위 | 판정 함수와 코덱 | 개발 | 자동 |
| 통합 | `rdl` 명령과 검사 결과 | 개발 | 자동 |

## 테스트 데이터와 환경

그림은 시험 안에서 만든다. 외부 파일을 두면 그 파일이 저장소에 남아 이 시험이 막으려는 문제를 자기가 일으킨다. 작업공간은 임시 디렉터리에 새로 만들고 끝나면 지운다 — 개발자 기계에 붙은 작업공간에 기대면 CI에서 죽는다.

## 통과 기준

- 아래 시나리오 전부가 통과한다.
- 네 OS·Node 매트릭스에서 같은 결과가 나온다.

## 기능별 검증 계약

### REQ-054#FN-001

#### 사전 조건

- 임시 작업공간에 프로젝트 하나가 있다.
- 그림은 시험 안에서 만든다.

#### 입력과 데이터

- 대비가 큰 격자 무늬 RGBA 화소. 최근접 이웃으로 줄이면 여기서 깨지므로 상자 필터를 쓰는지가 드러난다.
- 손으로 만든 GIF 헤더와 SVG 문자열.

#### 실행 절차

1. 화소로 PNG와 JPEG를 만든다.
2. `rdl asset add`를 각 시나리오의 인수로 실행한다.
3. 결과 파일의 차원을 헤더로 다시 읽는다.
4. 코덱 왕복은 함수를 직접 불러 확인한다.

#### 기대 결과

- 줄인 결과의 차원이 비율을 지킨다.
- 한계 이하 입력에서 반환된 버퍼가 원본과 같은 객체다.
- 거절된 시나리오에서 자산 디렉터리에 파일이 생기지 않는다.

#### 오류와 취소

- 줄이지 못하는 형식은 예외로 알린다. 원본을 그대로 통과시키면 사람은 줄었겠지 하고 넘어간다.

#### 증거

- `test/asset.test.js`의 PNG 코덱 구역과 축소 구역, 명령 구역.

#### 수용 기준

- [ ] 열 시나리오가 모두 통과한다.
- [ ] 네 OS 매트릭스에서 같은 결과가 나온다.
