# 업무 유형 정의 저장 형태 검증

## 목적과 범위

유형 정의가 맵 항목으로 저장되고 상속 규칙을 그대로 타는지, 카탈로그 밖 제약과 조건식 파라미터가 거부되는지, 면제가 허용 목록으로 동작하고 경계 층을 열지 못하는지를 검증한다. 제약이 어떻게 판정되는지는 검증하지 않는다.

## 테스트 수준

| 수준 | 대상 | 책임 | 자동화 여부 |
|---|---|---|---|
| 단위 | 정의 정규화 함수 | 개발 | 자동 |
| 통합 | 설정을 읽는 명령의 종료 코드와 메시지 | 개발 | 자동 |

## 시나리오

| ID | 사전조건 | 실행 | 기대 결과 | 우선순위 |
|---|---|---|---|---|
| RDLITEMSHAPE01 | 카탈로그 안의 제약만 있음 | 정의를 읽는다 | 정규화되고 표시 필드와 제약이 나뉜다 | 높음 |
| RDLITEMSHAPE02 | 카탈로그에 없는 제약 종류 | 정의를 읽는다 | 거부되고 종류 이름과 키 경로가 담긴다 | 높음 |
| RDLITEMSHAPE03 | 파라미터가 조건식 형태 | 정의를 읽는다 | 거부되고 값과 이름만 받는다고 알린다 | 높음 |
| RDLITEMSHAPE04 | 면제 가능 목록 안의 게이트 | 정의를 읽는다 | 면제가 선언된다 | 높음 |
| RDLITEMSHAPE05 | 경계 층 게이트를 면제에 적음 | 정의를 읽는다 | 거부되고 면제 대상이 아닌 이유가 담긴다 | 높음 |
| RDLITEMSHAPE06 | 면제 가능 목록 전체 | 목록을 훑는다 | 경계 층 게이트가 하나도 들어 있지 않다 | 높음 |
| RDLITEMSHAPE07 | 내장 유형 정의 | 정규화를 지난다 | 파일 정의와 같은 결과 형태가 나온다 | 높음 |
| RDLITEMSHAPE08 | 상위가 유형을 정의하고 하위가 제약 하나만 덮음 | 병합한다 | 그 제약만 덮이고 나머지는 상위 값 | 높음 |
| RDLITEMSHAPE09 | 하위가 새 유형 키를 더함 | 병합한다 | 상위 유형과 새 유형이 함께 남는다 | 높음 |
| RDLITEMSHAPE10 | 하위가 상속 유형에 사용 안 함을 명시 | 병합한다 | 결과에 남되 사용 안 함으로 표시된다 | 높음 |
| RDLITEMSHAPE11 | 유형 식별자에 한글이 들어감 | 정의를 읽는다 | 거부되고 식별자 형식을 알린다 | 중간 |
| RDLITEMSHAPE12 | 아직 없는 문서를 가리키는 파라미터 | 정의를 읽는다 | 형태만 보므로 통과한다 | 중간 |

## 비기능 검증

| 품질 속성 | 목표 | 환경 | 측정 방법 |
|---|---|---|---|
| 실패 방향 | 형태 판정이 애매하면 거부한다 | 로컬 | 판정 불능 입력에 대한 동작 확인 |
| 설명 가능성 | 정의 하나로 그 유형의 규칙을 다 말할 수 있다 | 로컬 | 정의와 실제 진단 목록의 대조 |
| 결정성 | 같은 정의면 같은 결과 | 로컬 | 반복 호출 결과 비교 |

## 테스트 데이터와 환경

정의는 시험 안에서 값으로 만든다. 제약 종류 목록과 면제 가능 게이트 목록은 코드에서 가져와 쓰고 시험이 다시 적지 않는다 — 다시 적으면 목록이 늘어날 때 새 항목이 검증되지 않은 채 남는다. 경계 층 게이트 목록도 코드에서 가져와, 그중 하나라도 면제 가능 목록에 들어오면 시험이 넘어지게 한다.

## 통과 기준

- 열두 시나리오가 모두 통과한다.
- 면제 가능 목록과 경계 층 목록의 교집합이 비어 있다.
- 네 운영체제와 실행기 조합에서 같은 결과가 나온다.

## 기능별 검증 계약

### ITM-01

#### 사전 조건

- 제약 종류 다섯과 면제 가능 게이트 목록이 코드에서 읽힌다.
- 경계 층 게이트 목록도 코드에서 읽힌다.

#### 입력과 데이터

- 파싱된 유형 정의 맵과 파일 경로.
- 계층별 정의 맵. 병합 시나리오가 쓴다.
- 경계 층 게이트 이름 하나. 면제 거부 시나리오가 쓴다.

#### 실행 절차

1. 시나리오가 정한 정의를 값으로 만든다.
2. 정규화를 호출한다.
3. 병합 시나리오는 계층별 정의를 만들어 병합까지 호출한다.
4. 결과 객체 또는 예외 메시지를 받는다.

#### 기대 결과

- 표시 필드와 제약이 결과에서 나뉘어 담긴다.
- 거부는 예외로 나오며 파일 경로와 키 경로와 이유가 담긴다.
- 면제 가능 목록과 경계 층 목록의 교집합이 비어 있다.
- 병합이 맵 규칙을 그대로 탄다.

#### 오류와 취소

- 거부는 첫 위반에서 멈춘다.
- 우회 경로가 없다. 판수를 올려도 경계 층 면제는 열리지 않는다.

#### 증거

- 유형 정의 시험 파일의 정규화 구역과 면제 구역과 병합 구역.

#### 수용 기준

- [ ] 면제 목록이 허용 목록으로 동작한다.
- [ ] 경계 층 게이트가 면제 목록에 없음이 전수로 확인된다.
- [ ] 내장 정의가 파일 정의와 같은 정규화를 지난다.
