# 정책 변경 결정 기록 검증

## 목적과 범위

정책 필드가 바뀔 때만 결정이 요구되는지, 기록에 이전 값과 새 값이 함께 담기는지, 위임 없는 대리 결정이 거부되는지를 검증한다. 결정 종류 카탈로그의 구성은 검증하지 않는다.

## 테스트 수준

| 수준 | 대상 | 책임 | 자동화 여부 |
|---|---|---|---|
| 단위 | 차이 판정 함수 | 개발 | 자동 |
| 통합 | 저장 경로와 결정 원장의 기록 | 개발 | 자동 |

## 시나리오

| ID | 사전조건 | 실행 | 기대 결과 | 우선순위 |
|---|---|---|---|---|
| RDLPOLICYDECIDE01 | 표시 필드만 다른 두 내용 | 저장한다 | 결정 없이 저장된다 | 높음 |
| RDLPOLICYDECIDE02 | 정책 필드가 다른 두 내용, 결정 없음 | 저장한다 | 거부되고 결정을 요구하는 필드가 메시지에 담긴다 | 높음 |
| RDLPOLICYDECIDE03 | 정책 필드가 다른 두 내용, 결정 있음 | 저장한다 | 저장되고 원장에 계약 변경 결정이 남는다 | 높음 |
| RDLPOLICYDECIDE04 | 정책 값을 조이는 변경 | 저장한다 | 푸는 변경과 같이 결정을 요구한다 | 높음 |
| RDLPOLICYDECIDE05 | 같은 값을 다시 적은 내용 | 저장한다 | 차이가 아니므로 결정을 요구하지 않는다 | 높음 |
| RDLPOLICYDECIDE06 | 키 순서와 공백만 다른 내용 | 저장한다 | 차이가 아니므로 결정을 요구하지 않는다 | 높음 |
| RDLPOLICYDECIDE07 | 위임받은 클라이언트가 결정을 냄 | 저장한다 | 저장되고 행위자와 결정자가 다르게 기록된다 | 중간 |
| RDLPOLICYDECIDE08 | 위임 없이 다른 구성원 명의로 결정 | 저장한다 | 거부된다 | 높음 |
| RDLPOLICYDECIDE09 | 정책 필드가 바뀌고 결정이 기록됨 | 기록에서 이전 값을 되읽는다 | 이전 내용이 복원된다 | 높음 |

## 비기능 검증

| 품질 속성 | 목표 | 환경 | 측정 방법 |
|---|---|---|---|
| 기록 완전성 | 기록만으로 이전 상태를 복원할 수 있다 | 로컬 | 기록에서 되읽어 원본과 대조 |
| 실패 방향 | 차이 판정이 애매하면 결정을 요구한다 | 로컬 | 판정 불능 입력에 대한 동작 확인 |
| 결정성 | 같은 두 내용이면 같은 차이 판정 | 로컬 | 반복 호출 결과 비교 |

## 테스트 데이터와 환경

임시 작업공간에 프로젝트와 클라이언트를 만들고 끝나면 지운다. 위임 시나리오는 시험 안에서 위임을 부여하고, 만료된 위임과 취소된 위임을 각각 따로 다룬다. 결정 원장은 임시 작업공간 안에 두어 개발자 기계의 원장을 건드리지 않는다.

## 통과 기준

- 아홉 시나리오가 모두 통과한다.
- 기록에서 이전 내용이 복원된다.
- 네 운영체제와 실행기 조합에서 같은 결과가 나온다.

## 기능별 검증 계약

### REQ-058#FN-001

#### 사전 조건

- 임시 작업공간에 프로젝트와 등록된 클라이언트가 있다.
- 결정 원장이 그 작업공간 안에 있다.

#### 입력과 데이터

- 저장 전 내용과 저장하려는 내용.
- 그룹별 필드 목록. 표시 필드와 정책 필드의 구분을 담는다.
- 행위 클라이언트와 소유 구성원, 그리고 시나리오가 정하면 결정과 위임.

#### 실행 절차

1. 임시 작업공간과 프로젝트와 클라이언트를 만든다.
2. 저장 전 내용을 설정 파일에 쓴다.
3. 위임 시나리오는 위임을 먼저 부여한다.
4. 새 내용으로 저장을 호출한다. 시나리오가 정하면 결정을 함께 제시한다.
5. 결과와 결정 원장의 내용을 읽는다.

#### 기대 결과

- 정책 차이가 있으면 결정 요구가 참이고, 표시 차이만 있으면 거짓이다.
- 저장된 결정에 바뀐 필드마다 이전 값과 새 값이 있다.
- 행위자와 결정자가 다르면 근거가 된 위임이 기록에 함께 있다.
- 위임 없는 대리 결정은 저장되지 않는다.

#### 오류와 취소

- 결정이 필요한데 없는 경우와 위임 없는 대리 결정을 서로 다른 메시지로 구분한다.
- 저장 전에 멈추면 설정 파일과 원장 둘 다 그대로다. 결정만 남고 저장이 안 된 상태를 만들지 않는다.

#### 증거

- 정책 변경 기록 시험 파일의 차이 판정 구역과 위임 구역.

#### 수용 기준

- [ ] 정책 차이에만 결정 요구가 참이 된다.
- [ ] 기록에서 이전 내용이 복원된다.
- [ ] 위임 없는 대리 결정이 거부된다.
