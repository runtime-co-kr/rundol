## 테스트 데이터와 환경

버전 관리 fixture와 OS 임시 디렉터리의 npm prefix, cache, CODEX_HOME, CLAUDE_CONFIG_DIR, RUNDOL_COPILOT_HOME을 사용한다. 실제 사용자 home과 registry 자격 증명은 사용하지 않고 종료 시 정리한다.

## 통과 기준

- `node test/doctor.test.js`, `node test/skill-install.test.js`, `npm run test:install`이 모두 통과한다.
- 손상·unmanaged 시나리오가 정확한 error/warn을 내고 사용자 파일을 보존한다.

## 기능별 검증 계약

### REQ-023#FN-001

#### 사전 조건

- Node/npm/Git가 테스트 최소 버전을 만족하고 fixture, package tarball과 격리된 Client home을 준비한다.

#### 입력과 데이터

- 정상/손상 package, 5종 Git 오류 문자열, missing/stale/unmanaged/current 스킬 상태를 사용한다.

#### 실행 절차

- doctor API·CLI를 실행하고 package를 tarball 설치해 손상 진단한다. 스킬 설치를 두 번 수행하며 두 번째 전에 unmanaged 상태를 만든다.

#### 기대 결과

- check 상태와 summary가 실제 환경을 반영하고 각 오류에 remediation이 있으며 managed 대상만 current로 갱신된다.

#### 오류와 취소

- check 하나의 실패가 나머지 진단을 중단하지 않는다. unmanaged target은 skip되어 원본이 유지되고 임시 설치 실패는 테스트 실패로 종료한다.

#### 증거

- doctor JSON, CLI 종료 코드, 설치 디렉터리와 `.rundol-managed.json`, stderr 보존 경고, 세 테스트 로그.

#### 수용 기준

- REQ-023의 최소 버전, package 무결성, postinstall 분리, 오류 분류, 스킬 설치와 비파괴 기준을 입증한다.
